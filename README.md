# TURBO // Open Source Aquarium Knowledge Base

> **Command Directive**: Centralized open-source repository aligning all life-support systems, tank engineering specifications, filtration architectures, and media formulations across freshwater, brackish, and marine habitats.

---

## 🔬 Core Disciplines

### 1. `tanks/`
- Enclosure engineering: float glass, low-iron optiwhite, acrylic stress thresholds.
- Load-bearing foundation physics: weight per gallon, stand deflection tolerance.
- Habitat classification: planted high-tech, turtle riparium/paludarium, blackwater, African cichlid rift lake, reef ecosystems.

### 2. `filters/`
- Staging orders: Mechanical intake -> Biological reactor -> Chemical polishing.
- Form factors: Canister pressurization, sump baffling & weir overflow rates, internal power filters, HOB cascades, air-driven sponge arrays.
- Fluid dynamics: Turnover rates ($GPH / LPH$), head pressure curves, zero-bypass chamber sealing.

### 3. `media/`
- **Mechanical**: Course-to-fine polyfoam (10 PPI -> 20 PPI -> 30 PPI), filter floss, bonded batting.
- **Biological**: Sintered glass, porous ceramic rings, volcanic pumice, bio-balls, fluidised K1 media (Specific Surface Area $m^2/m^3$).
- **Chemical / Adsorptive**: Activated lignite/bituminous carbon, synthetic macroporous polymer adsorbents, ion-exchange resins, GFO (Granular Ferric Oxide).
